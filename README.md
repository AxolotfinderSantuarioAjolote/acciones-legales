# Acciones Legales — Santuario Ajolote

Denuncias ambientales, Demanda Arca Tierra y defensa legal del humedal de Xochimilco. CIMA A.C. documenta y presenta acciones legales ante autoridades ambientales por el deterioro del ecosistema.

## Contenido

1. Demanda Arca Tierra
2. Denuncias CIMA A.C.
3. Marco legal aplicable
4. Autoridades competentes: PROFEPA, SEDEMA, CONAGUA, PAOT
5. Modelos de denuncia ciudadana
